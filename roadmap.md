# Roadmap – geplante Erweiterungen (Stand 26.09.2026)

Auswahl des Users: Zentrale & Fahrer priorisiert.

## Erledigt: Persönliche Oberflächengröße für Fahrer
- [x] Auswahl im Profil: Standard, Groß oder Sehr groß
- [x] Persönlich je Gerät speichern und auf die gesamte angemeldete Oberfläche anwenden

## Erledigt: Checklisten für Einsätze
- [x] Vorlagen pro Domäne, pro Einsatztyp (AV-Einsatz / Hausnotruf / Beide), Pflichtpunkte
- [x] Fahrer startet Checkliste am Einsatz, hakt Punkte ab, schließt ab
- [x] Admin-Verwaltung unter /admin → Reiter „Checklisten"

## Erledigt: Push-Benachrichtigungen
- [x] Web-Push für neue Einsätze an Fahrer & Zentrale (Service Worker + VAPID)
- [x] Abo-Verwaltung pro Benutzer (Schalter im Profil, „Test senden")

## Erledigt: Objektdossier
- [x] Eigener Menüpunkt „Objektdossier" (Admin/Disponent), Liste mit Suche
- [x] Dossier je Kunde: Anfahrt, Parken, Schlüssel, Alarmplan, Gefahren, Technik, Öffnungszeiten, Notiz
- [x] Notfall-/Objektkontakte mit Telefon-Link, zugeordnete Dateien
- [x] „Objektinfo"-Button auf den Einsatzkarten der Fahrer (schreibgeschützt)
- [x] Sichtbarkeit je Dossier für Fahrer abschaltbar

## Erledigt: Service Center füllen
- [x] Aufträge erfassen (Nummernkreis je Domäne), Typ/Status/Priorität, Wiedervorlage
- [x] Status-Tabs, Suche, Überfällig-Schalter, Kennzahlen
- [x] Zuweisung an Teammitglied, Notizen-Verlauf
- [x] „Einsatz anlegen" übergibt Kunde, Adresse, Schlüssel-Nr., Teilnehmer und Grund an die Einsatzmaske
